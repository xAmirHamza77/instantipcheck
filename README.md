## About

InstantIPCheck is a free "What Is My IP" checker and lookup tool. It shows your public IPv4 and IPv6 addresses instantly, together with your approximate (city-level) location, ISP, hostname and ASN.

Alongside the checker it offers a small set of privacy tools: an IP lookup for other addresses, a DNS leak test, a WebRTC leak test and VPN privacy checks — all free, with no signup.

## Features

- Shows your public IPv4 and IPv6 addresses instantly
- Approximate (city-level) location, ISP, hostname and ASN
- IP lookup for other addresses
- DNS leak test and WebRTC leak test
- VPN privacy checks
- Free, no signup or account
